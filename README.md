## 🚀 Featured Projects

### 🔍 Vehicle Forensic Matching System

<div align="center">

[![View on GitHub](https://img.shields.io/badge/GitHub-Vechile__forensic__match__RAC-0d1117?style=for-the-badge&logo=github&logoColor=white)](https://github.com/kulkarnishub377/Vechile_forensic_match_RAC)

</div>

> **Challenge:** Manual vehicle identification from surveillance footage was slow and error-prone across databases of 150,000+ entries.

| Component | Technology | Result |
|:---|:---|:---|
| Visual Embeddings | ResNet + OSNet (5,632-dim fusion) | Fine-grained identity matching |
| Vector Search | FAISS IVF Indexing | **30× faster retrieval** |
| OCR Layer | PaddleOCR — license plate recognition | Text-based cross-verification |
| API & Serving | FastAPI + Redis (async) | **150K+ queries/day · sub-1s response** |

<br/>

### 📄 Document AI + RAG Pipeline

<div align="center">

[![View on GitHub](https://img.shields.io/badge/GitHub-Document--AI---RAG--Pipeline-0d1117?style=for-the-badge&logo=github&logoColor=white)](https://github.com/kulkarnishub377/Document-AI---RAG-Pipeline)

</div>
